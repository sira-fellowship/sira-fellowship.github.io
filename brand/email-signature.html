SIRA email signature

  1. Select everything inside the white box below (drag from “Warmest regards” to the logo) and copy (⌘C).
  2. In Gmail: Settings → See all settings → General → Signature → Create new, name it “SIRA”.
  3. Paste (⌘V) into the signature box, then set it as the default for emilio@sirafellowship.org (the “For new emails use” and “On reply/forward use” menus) and click Save Changes at the bottom.
