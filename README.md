# SIRA: Societal Impacts Research on AI

Website for SIRA, a proposed mentored research fellowship that gives social scientists a structured path into AI safety.

Live at https://sira-project.org

The site is plain HTML and CSS (`index.html`, `style.css`) with no build step. GitHub Pages serves it from the `main` branch; `CNAME` sets the custom domain.

## Logo

The logo kit is in `brand/` (see `brand/README.md`): the mark spells SIRA in Morse code. `tools/logo.py`, `tools/logo_png.sh`, and `tools/contact_sheet.py` regenerate every logo file, the favicons, and the link-preview image.
